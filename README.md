# TGP_Asteroids2_2025

Code used for analysis of data for the Telescope Group Project running in 2025/26.

This body of code was written by the Asteroids 2 group members, including Robero Seminara, Aroha Millichip, and Matylda Rejus. 
It includes code files for reduction, photometry, astrometry (kind of), and period analysis of FITS observation images of a small Solar System body. All code is formatted into Jupyter notebook files for interactivity and easy display. The repo also contains astronomical exercises from Observational Astronomy (24/25) as a starting point for some of the code, as well as some of our observation data.
